# README — Лабораторная работа №5

## Игра «Симон говорит» (Simon)

**Что это:** классическая игра на память. Компьютер показывает последовательность из 4 цветных секторов, игрок повторяет. С каждым успешным раундом последовательность удлиняется на 1. Ошибся — игра окончена, показан достигнутый уровень.

## Как выполнено задание

**Разметка.** 4 кнопки-сектора (`.pad`) выложены через CSS Grid в сетку 2×2 и за счёт `border-radius` складываются в круг. В центре — консоль с кнопкой «Старт». Всё обёрнуто в `IIFE` со `'use strict'`, чтобы не мусорить в глобальной области.

**Состояние** — объект `state`: массив последовательности, сколько шагов игрок уже верно ввёл, флаги `isPlaying` и `isShowing`, массив активных таймеров, ленивый `AudioContext`.

**Таймеры под контролем.** Каждый `setTimeout` проходит через обёртку `schedule()`, которая сохраняет id в `state.timers`. Есть `clearAllTimers()` — вызывается при новой игре и при проигрыше. Зависших таймеров нет, проверил несколько игр подряд.

**Показ последовательности** — `async/await` + Promise-обёртка `wait()` над `setTimeout`. Проходим по всей последовательности с начала: подсветка на 500мс, пауза 250мс. Во время показа сектора заблокированы (`disabled`).

**Ввод игрока.** Клики по секторам проверяют `state.sequence[state.playerIndex]`. Верно — счётчик ввода растёт; дошли до конца — добавляем новый случайный элемент и запускаем показ заново. Ошибка — `gameOver()`.

**Проигрыш.** Сбрасываю таймеры, блокирую сектора, показываю «Вы дошли до уровня N» и короткую прощальную подсветку всех секторов по очереди.

**Счёт и статус** выводятся в HUD: текущий уровень и текстовый статус («Показ…», «Ваш ход», «Игра окончена»).

**Звук** — по желанию, добавил через `AudioContext` (`playTone`), чтобы не тащить аудиофайлы.

## Оформление

Тёмная тема «под пластиковую игрушку»: объёмные сектора с бликами и внутренними тенями, свечение при подсветке. В углах экрана — крупные полупрозрачные буквы М/И/К/Н, которые загораются в цвет активного сектора через `:has()`. Центральная консоль с надписью SIMON и красной кнопкой «Старт» в классическом стиле. Уважается `prefers-reduced-motion`.
