# README — Лабораторная работа №7

## Лента постов с бесконечным скроллом

**Что это:** лента постов из JSONPlaceholder. При скролле до конца автоматически подгружается следующая порция по 10 штук, есть поиск по заголовку и индикатор загрузки.

## Как выполнено задание

**Данные.** Все загруженные посты хранятся в массиве `allPosts`. Отрисовка и фильтрация идут только по нему — повторных запросов к серверу при поиске нет.

**Загрузка.** `fetchPosts()` делает запрос к API с `_start` и `_limit` — подгружается ровно следующая страница по 10 постов. Вся логика на `async/await`, каждый `fetch` обёрнут в `try/catch`. При ошибке (сеть или `response.ok === false`) показываю понятное сообщение и кнопку «Повторить».

**Бесконечный скролл.** Слушаю `scroll` на `window`. Если до конца страницы осталось меньше 200px — вызываю `loadMore()`. Флаги `isLoading` и `hasMore` не дают запускать параллельные загрузки и крутить их бесконечно. Когда загружены все 100 постов — показываю «Больше постов нет». Есть `fillScreenIfNeeded()`: если экран большой и страница ещё не прокручивается, догружаю сразу.

**Поиск.** Дебаунс 300мс через `setTimeout`/`clearTimeout` — фильтр применяется только когда пользователь перестал печатать. Фильтрация по подстроке в заголовке, без учёта регистра. Если ничего не найдено — сообщение.

**Рендер.** Функция `render()` очищает ленту и строит карточки из отфильтрованного массива через `map(createCard)`. Карточка собирается через `document.createElement`, без innerHTML.

**Статус** — единый блок под лентой: спиннер при загрузке, сообщение об ошибке, «Больше постов нет» или «Ничего не найдено».

## Оформление

Светлая минималистичная тема, липкая шапка с поиском, карточки с лёгкой тенью и скруглениями. Аватар автора — кружок с номером. Спиннер на CSS, `aria-live` для статуса.
