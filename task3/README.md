# README — Лабораторная работа №3

## Todo-list на чистом JavaScript

**Что это:** интерактивный список задач. Добавление, удаление, отметка «выполнено», счётчик и фильтры «Все / Активные / Завершённые». Данные между перезагрузками не сохраняются — localStorage по заданию не нужен.

## Как выполнено задание

**Хранение данных.** Задачи лежат в массиве объектов вида `{ id, text, completed }`. Уникальный id — счётчик `nextId`, который растёт на 1 при каждом добавлении. Текущий фильтр — отдельная переменная `currentFilter`.

**Рендер из массива.** Функция `render()` очищает список и заново строит его из данных: `getVisibleTasks()` через `filter` отбирает задачи по текущему фильтру, `map(createTaskElement)` создаёт DOM-элементы. HTML задач в разметке не прописан — всё генерируется в JS через `document.createElement`.

**Добавление.** По кнопке и по Enter. Пустой ввод (или одни пробелы) не добавляется — показывается предупреждение, которое скрывается, как только пользователь начинает печатать.

**У задачи есть** чекбокс (переключает `completed`, текст зачёркивается через класс `.completed`) и кнопка «Удалить» (убирает задачу из массива через `filter`).

**Счётчик** показывает «Осталось: N, Выполнено: M» и пересчитывается при каждом изменении.

**Фильтры** — три кнопки. Клик меняет `currentFilter`, подсвечивает активную кнопку и перерисовывает список. Задачи не удаляются, а просто не попадают в выборку.

**События** — только через `addEventListener`, никаких `onclick` в HTML. Ошибок в консоли нет.

## Оформление

Розовая тема, карточка по центру, фон с фотографией и затемнением. Есть `transition` на кнопках, полях и карточках задач, `:hover` и `:focus` состояния.
