# Лабораторная работа №1 — Семантическая вёрстка

Страница-резюме на чистом HTML + CSS, без JavaScript.

## Что внутри
- Семантическая разметка: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Раскладка блоков через Flexbox
- Навыки оформлены как «пилюли» через `<span class="skill">`
- Контактные ссылки: mailto:, GitHub, tel: — с ховер-эффектами
- Якорная навигация по секциям

## Файлы
- `index.html` — разметка
- `style.css` — стили
- `photo_2026-09-17_13-19-28.jpg` — аватар

## Как посмотреть
Открыть `index.html` в браузере или перейти по GitHub Pages:
`https://miroslavyukhnevich.github.io/web-course-2026/task1/`

## Технические детали
- `box-sizing: border-box` глобально
- Flexbox: `justify-content`, `align-items`, `flex-direction`, `flex-wrap`, `gap`
- Без `float` и `position: absolute/fixed` в раскладке
- Без инлайн-стилей и `<style>` в HTML
