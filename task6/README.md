# README — Лабораторная работа №6

## Игра «Змейка» на Canvas

**Что это:** классическая змейка. Управление WASD/стрелками, сбор яблок, рост, счёт и рекорд. Столкновение со стеной или хвостом — конец игры. Перезапуск без перезагрузки страницы.

## Как выполнено задание

**Поле.** Canvas 400×400, сетка 20×20 клеток по 20px. Размеры вынесены в константы (`CELL_SIZE`, `GRID_SIZE`), поле рисуется картинкой `field.svg` + шахматная подсветка сверху.

**Состояние** — объект `state`: массив сегментов змейки, текущее направление, очередь поворотов, яблоко, счёт, рекорд, флаги `running` / `gameOver`, время последнего шага и прогресс шага для плавной анимации.

**Игровой цикл** — через `requestAnimationFrame`, без `setInterval`. В `update(now)` считаю прошедшее время с `lastMoveTime`: змейка двигается только когда прошло `MOVE_INTERVAL` (130мс). Скорость одинаковая на любом мониторе, от частоты кадров не зависит. Логика (`update`) и отрисовка (`draw`) разделены.

**Разбиение на функции:** `initGame`, `spawnApple`, `checkCollision`, `moveSnake`, `queueTurn`, `drawField`, `drawApple`, `drawSnake`, `drawHead`, `drawBodySegment`, `startGame`, `endGame`, `updateHUD`. Никакой свалки в одном обработчике.

**Яблоко** спавнится только в свободной клетке — перебираю все клетки, вычитаю занятые змейкой, выбираю случайную из оставшихся.

**Повороты.** Разворот на 180° игнорируется: проверяю, что новое направление не противоположно последнему. Чтобы управление было отзывчивым, держу очередь поворотов (до 3) и если шаг уже прошёл больше 35% — двигаю змейку сразу, не дожидаясь следующего тика. Плавность обеспечивается интерполяцией позиции сегментов по `tickProgress`.

**Конец игры** при выходе за границы или столкновении с телом (хвост не считается, если змейка на этом шаге растёт). Показывается оверлей с итоговым счётом и рекордом, кнопка «Ещё раз» и Enter/Space работают.

**Клавиатура.** WASD и стрелки, `event.preventDefault()` чтобы страница не скроллилась. `repeat` игнорируется.

## Оформление

Тёмно-зелёная тема, полупрозрачные панели с `backdrop-filter`, лаймовый акцент. Голова змейки с глазами и языком, тело с плавным градиентом, яблоко с бликом и тенью. Оверлеи с плавным появлением, уважается `prefers-reduced-motion`.
