# README — Лабораторная работа №4

## Игра «Быки и коровы»

**Что это:** браузерная игра на чистом JS. Компьютер загадывает 4 неповторяющиеся цифры, игрок угадывает. После каждой попытки показываются быки (цифра на своём месте) и коровы (цифра есть, но не на месте).

## Как выполнено задание

**Состояние** хранится в объекте `state`: загаданное число, счётчик попыток, массив истории, флаг окончания игры и лучший результат.

**Генерация числа** — отдельная функция `generateSecret()`. Беру массив цифр 0–9, перемешиваю алгоритмом Фишера–Йетса и беру первые 4. Повторов быть не может по определению.

**Валидация** — отдельная функция `validateGuess()`. Проверяет: не пусто, ровно 4 символа, только цифры (регулярка), все цифры разные (через `Set`). При ошибке — сообщение и анимация тряски, попытка не засчитывается.

**Подсчёт быков и коров** — отдельная функция `countBullsAndCows()`. Прохожу по цифрам: если совпала позиция — бык, иначе если цифра вообще есть в секрете — корова.

**История** рендерится из массива `state.history` функцией `renderHistory()`, а не дописывается в innerHTML. Каждая запись — цифры и бейджи с быками/коров. Есть склонение слов («1 бык», «2 быка», «5 быков») через отдельную функцию `pluralize`.

**Победа.** Если быков 4 — игра завершена, поле и кнопка блокируются, выводится сообщение с количеством попыток. Если результат лучше предыдущего — обновляется лучший счёт.

**Новая игра** сбрасывает всё: новое число, пустая история, счётчик на 0, поле разблокировано.

**Ввод** фильтруется на лету — только цифры, максимум 4. Работает и по кнопке, и по Enter. Визуальные ячейки подсвечиваются по мере ввода.

## Оформление

Тёмная тема с фоновой картинкой, полупрозрачная карточка с `backdrop-filter: blur`. Есть анимации (появление цифры, тряска при ошибке, выезд истории), `prefers-reduced-motion` уважается. На узких экранах поле и кнопка перестраиваются в колонку.
