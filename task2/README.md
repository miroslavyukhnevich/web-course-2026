## Как выполнено задание

**Mobile First.** Базовые стили — для мобильных (до 767px), дальше два медиазапроса: @media (min-width: 768px) для планшета и @media (min-width: 1200px) для десктопа. Запросов max-width нет.

**Grid + Flexbox по назначению.**
- Grid — крупная сетка: hero-секция (текст + картинка) и сетка карточек игроков (1 колонка на мобильном → 2 на планшете → 3 на десктопе).
- Flexbox — компоненты: шапка, логотип, навигация, содержимое карточки, форма, кнопки.

**Меню-гамбургер.** На мобильном навигация скрыта, иконка нарисована тремя span. По классу .nav--open меню раскрывается, бургер анимируется в крестик. JS добавил для удобства — по заданию клик не требовался, но пусть работает.

**Форма обратной связи.** Поля «Имя», «Email», «Сообщение» + кнопка. У полей есть :hover (рамка меняет цвет) и :focus (акцентная рамка + тень). Отправка не реализована — только вёрстка.

**Анимации.** transition на кнопке (фон + scale), на карточке при наведении (transform: scale(1.03) + тень), на полях формы.

**Touch-friendly.** Кнопки, бургер и поля — не меньше 44×44px.

**Проверка.** Горизонтального скролла нет на всех ширинах, проверил через DevTools (Ctrl+Shift+M).
